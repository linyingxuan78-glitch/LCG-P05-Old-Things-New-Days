## 开发与测试可以分开，但不能等全部开发完才第一次运行

当前各项 Python 审计只验证结构、文件、哈希与测试脚本的判定逻辑；
它们**不是 Godot 编译测试、实际帧画面检查，也不是儿童安全或光敏性认证**。
下一道必要关口是获得 Godot 4.4.1 标准版后依次执行：资源导入、主场景启动、23 组原生自动测试。
之后应通过 Windows 机器进行 720p/1080p 的真机画面测试、真人理解测试、性能和闪烁风险评估；
最后才能制作单文件或自包含 EXE，检查所有许可证，并评估年龄分级与平台规则。

## 给开发者的最短操作路径

1. 解压当前唯一最新版 ZIP，在 Godot 4.4.1 中打开 `project.godot`。
2. Windows 双击 `run_check_windows.cmd`，或 Linux 执行 `tools/run_native_acceptance.sh`。按提示检查 `documentation/native_run_logs/` 下报告。
3. 未见 `PASS: Godot ... 23 headless QA suites` 前，不得宣称原生验收完成。
4. **不要把这个 ZIP 直接发给玩家冒充可以双击运行的游戏。**
