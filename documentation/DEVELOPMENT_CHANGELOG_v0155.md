# LCG-P05 v0.15.5 开发变更 / 2026-11-22

## 本轮实装
- 增加每日居民转让报价：第二天起、每天一件、按已解锁商品轮换；对比正常供应成本给出较低收购价。
- 新经营桌入口和可退出的报价界面；资金、手持物、共享货架容量都限制收购；每个报价只能处理一次。
- 收购物品必须正常上架；收购现金流写入经营支出；供货商每日配额不受影响。
- 保存报价商品、价格、处理结果和累计购买统计；旧存档自动迁移，不改变存档路径。
- Godot 自动验收脚本从 11 组增加至 12 组；Linux 和 Windows 验收流程及模拟测试器同步更新。

## 测试情况
- Static audit: 旧的 13 项模型、动画、授权检查通过；新的 11 项本地转让结构审计通过。
- QA runner simulation: 正常成功、失败退出、错误消息和错误通过标记均正确判定（**这是测试器模拟，不是游戏运行**）。
- Native Godot: BLOCKED_ENGINE_NOT_INSTALLED。不能声称游戏已经可稳定启动、UI 无遮挡、角色动画无异常或可发行。
