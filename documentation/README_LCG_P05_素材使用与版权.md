## 为什么不把所有素材都用完？
仅按游戏主题及当前开发功能选择：商店、家具、人物、UI、经营音效。节庆、科幻、像素、战斗及卡牌类素材先不投入工程，避免发布包膨胀、游戏风格错乱、导出与测试难度上升。

## 可否在解压后删除原始素材 ZIP？
**对于当前 Godot 工程本身**：脚本使用 `res://assets/...` 的工程内路径，不依赖玩家原始上传 ZIP，理论上删掉上传素材 ZIP 不影响已经复制到项目的资源。但仍要经过 Godot 实际启动与导出测试才能认定最终玩家包独立运行。

## 商业发布前
逐文件索引仅构成**可追溯记录**，不等于法律保证。CC0 通常不要求署名，但仍需核实来源及任何其他第三方权利。游戏标题、AI 辅助生成的 Logo 与最终商标尚未经正式清查。
