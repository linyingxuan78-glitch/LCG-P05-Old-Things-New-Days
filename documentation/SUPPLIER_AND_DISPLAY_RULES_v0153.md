# v0.15.3 商品、供货与陈列规则

1. **九个实体陈列区、27 种 SKU**：同一实体货架上最多六件，三种 SKU 轮流分享位置。实体货架只显示货品及合计容量，完整SKU售价在 Store Desk 浏览。
2. **经营桌三页**：每页九种 SKU；操作按钮随着翻页动态指向 SKU。玩家可用键盘 `TAB` 打开经营桌。
3. **供应商**：前九个基础商品长期供货，后18个商品按 `(商品索引+营业日)%4 != 0` 轮换库存。买不到新货时不会扣钱；换一天再查看。
4. **解锁**：部分二手商品需要累计售出 3、8 或 12 件才能进货。不会因为前一个档案缺少新增 SKU 而重新开局。
5. **品相**：`Well-Loved`、`Good`、`Excellent` 为新品 SKU 固定品相；本版不是逐件随机的旧物瑕疵系统。进货成本分别乘 0.84、1、1.22 后取整；销售价格仍由玩家自主定价。
6. **购买**：采购1件变为手持，进入商店后通过经营桌 `STOCK` 或拿商品面对所属货架按 `E` 上架。达到该陈列区六件上限则停止采购。
7. **三件批发**：累计销售≥3，SKU已解锁且当天有货、共享货架至少空三格、资金足够才可购买，批发价约为三件进价的九折。
8. **客流与结局**：顾客从已有库存和允许商品中选购，可因缺货或价格高离店；保持独立经营报表和可选软结局。
9. **限制**：仍为原型，不能证明这一套数值、客流、进货频率和UI页数对真实玩家最合适；需要 Godot 运行及玩家测试。
