# LCG-P05 视觉统一规范 / v0.15.1

**目标：**温馨、可读的欧美卡通低多边形 3D 二手商店。不是高写实、像素 RPG、Voxel 或弹珠轨道风格。

- 场景材质：低细节、哑光、适度圆角。避免一个道具全写实而邻近道具极端 Q 版。
- 既有配色：鼠尾草绿 `#82917B`、胡桃木棕 `#A57754`、米白 `#EFE8DC`、黄铜色 `#BEA16E`、深绿 `#25302C`。新增店招采用深绿底＋暖白文字。
- 灯光：日光＋暖色室内照明；新资产优先复用 Kenney 的 GLB 低多边形配色。
- 字体/UI：同一菜单色、按钮圆角、聚焦金色轮廓、禁用暗灰绿。HUD 和教程保持强对比。
- 摄像机：继续保留第一人称 3D；绝不因出现 2D 插画素材而改换 2.5D 镜头。
- 动作：避免硬切风格。未经模型比例和动作测试的角色动画不可宣称已经接入。
- Godot 实际场景和互动仍需实机截图、色彩对比与帧率检查；本轮只完成代码与素材风格预审。

## 3D 模型比例检查（trimesh 离线 GLB 几何体测量）

- 已读取 Mini Shop 和 Furniture Kit 六个可选 GLB 的实际几何边界（不代表 Godot 最终屏幕画面）。
- 旧代码中衣架高约 0.91m、人体模型约 0.61m、包袋货架约 0.90m，明显低于本游戏 1.86m 的商店货架。
- 本轮对衣架、人体模型、包袋货架、搬运车和衣帽架重新标定到约 1.3–1.7m 高，移动衣架及人体模型，减少与固定货架潜在的视觉交叉。
- 对购物篮保留 0.21m 高（接近实际随手篮子的相对尺度），避免所有物品统一放大。
- 这些数值仍须通过 Godot 实际画面与碰撞/遮挡截图核实，不能据此声称场景已经视觉验收通过。
