DEVELOPER ONLY / NOT A PLAYER FILE
==================================
1) Install or locate Godot 4.4+ standard editor and matching Windows export templates.
2) Open this project in Godot; wait for import, check errors, and run all 23 QA scripts.
3) Visually test the storefront, input, scaling, audio and sale/save paths.
4) Only after passing, export Windows Desktop via Project > Export, with Embed PCK enabled.
5) Confirm dist/LCG-P05.exe is the only player-facing game executable; do not ship the Godot project source to ordinary players.
6) Start the EXE in a clean directory without any original uploaded asset ZIPs. Test audio, models, and save behavior.
7) Keep LEGAL notices available in game credits; final license/title review before public distribution.
No Godot executable/templates are bundled in this source ZIP.
